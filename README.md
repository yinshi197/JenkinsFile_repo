# Jenkins Demo Repository

这是一个用于学习 Jenkinsfile 和 Jenkins Pipeline 的示例仓库。

目录说明：
- `scripts/` : 构建和测试脚本
- `src/` : 示例源代码
- `pipeline/` : 多条 Jenkins Pipeline 示例
- `docs/` : Jenkins Git 插件核心功能演示（含 4 个演示任务配置与说明手册）
- `Jenkinsfile` : 默认 Pipeline 示例
- `Dockerfile` : 可选 Docker 集成

Jenkins Git 插件演示手册见 [`docs/jenkins-git-plugin-demo.md`](docs/jenkins-git-plugin-demo.md)。
